## Purpose

Lets users copy the one-time password (TOTP/HOTP) code for a selected
password-store entry to the system clipboard directly from the picker.

## ADDED Requirements

### Requirement: Copy OTP code with <C-o>
While the password picker is open, the system SHALL copy the OTP code for
the entry under the cursor to the system clipboard when `<C-o>` is pressed.

#### Scenario: Copy OTP code for the selected entry
- **WHEN** the user presses `<C-o>` in the picker with an entry selected that has an OTP secret
- **THEN** the OTP code for that entry is copied to the system clipboard (`+` register)

#### Scenario: Picker remains open after copying OTP
- **WHEN** the user presses `<C-o>` in the picker
- **THEN** the picker stays open so the user can run further actions

### Requirement: Notify when entry has no OTP secret
If the selected entry has no OTP secret (no `otpauth://` URI in its
content), the system SHALL NOT copy anything to the clipboard.

#### Scenario: Entry without an OTP secret
- **WHEN** the user presses `<C-o>` in the picker with an entry selected that has no OTP secret
- **THEN** the system shows an error notification naming the entry
- **AND** nothing is copied to the clipboard

### Requirement: Copy is equivalent to `pass show` password copy
The OTP code SHALL be retrieved from the `pass` CLI and placed on the
clipboard in the same way password copies are handled.

#### Scenario: Clipboard receives the OTP code
- **WHEN** the user presses `<C-o>` in the picker for an entry with an OTP secret
- **THEN** the `+` register contains the OTP code generated by the `pass` CLI
